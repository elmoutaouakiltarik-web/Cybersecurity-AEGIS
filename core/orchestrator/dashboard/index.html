 Personal Cybersecurity Suite Roadmap

          
        

        

          
LayerStato reale nel progettoModulo/azione disponibileGap operativo

          
            

              Perimetro
              partial
              CrowdSec ingest, SOAR playbook definitions, WireGuard availability inventory
              Installare/configurare CrowdSec bouncer e WireGuard; AEGIS non forza blocchi senza backend reale.
            

            

              Endpoint
              implemented
              Windows audit, Defender status, process/connection inspection, YARA/hash scan, secrets sweep, ClamAV path scan, OSQuery agent support
              Installare ClamAV, OSQuery, Gitleaks/TruffleHog se si vogliono quei motori esterni.
            

            

              Rete
              implemented
              LAN discovery, authorized host scan, Nmap enrichment when installed, TLS inspector, topology, Suricata ingest
              Suricata deve essere avviato come servizio esterno o container; OT aggressive scan resta opt-in.
            

            

              Identità
              partial
              Secrets sweeper locale, Vaultwarden/OpenBao service inventory, hardening checks for risky local accounts
              Vaultwarden/OpenBao sono rilevati se installati/configurati; non vengono creati vault automaticamente.
            

            

              Dati
              partial
              BitLocker audit, report/export, event persistence, integrity-focused endpoint audit
              Age/BorgBackup/VeraCrypt non sono ancora integrati come job eseguibili; serve configurazione esplicita dei percorsi backup.
            

            

              Intelligence
              partial
              Threat intel lookup, CVE search, vulnerability module, ML service, OpenVAS/GVM/Nikto/Lynis availability inventory
              OpenVAS/GVM e Nikto richiedono installazione e target autorizzati prima di lanciare scan reali.
