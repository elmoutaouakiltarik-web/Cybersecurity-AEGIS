# Screenshots

Captured from a **local AEGIS instance** at 1440×900, running the current build
against synthetic sample events pushed through `/api/v1/ingest/generic`.

| File | View | Shows |
|---|---|---|
| `soc-overview.png` | SOC Overview | Live event feed over SSE, module posture, severity distribution |
| `shield-engine.png` | Shield Engine | Detection rule inventory, hit counts, severity trends |
| `ot-control.png` | OT Control | Passive OT/ICS visibility, protocol inventory, write-command signals |
| `threat-intel.png` | Threat Intelligence | IOC registry, feed health, enrichment results |
| `siem-correlation.png` | SIEM Correlation | Sigma-style rules, correlated incidents, deduplication |
| `plant-assessment.png` | Plant Assessment | Read-only industrial network assessment results |

## Provenance

- Hostnames, IPs and event payloads are **synthetic** and intentionally
  reserved/routable example ranges. No customer, production or personal data
  is present.
- No credential, token or password is displayed in any of the views.
- Files contain no EXIF/XMP metadata (PNG written by headless Chrome without
  metadata blocks).

## Refreshing

Screenshots are not generated by CI. To refresh them, start the orchestrator
locally, ingest a handful of sample events, then capture the six views above in
a browser at 1440×900 and overwrite the files in this directory.
